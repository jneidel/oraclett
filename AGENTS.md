# Agents.md

## Build and run
- `pnpm build` to transpile the app into `dist/`
- `./bin/run` run the cli app
- `pnpm test` to run the tests
- `pnpm lint` to lint code files

## Commit instructions
- Create modular commits; you may group by topic or action.
- Write the commit subject in the imperative mood and capitalize the first letter.
- In the commit body explain the what and why, if necessary.

## Markdown documentation
- Use `doctoc --maxlevel 3 README.md` to generate the table of contents instead of updating it manually.
- Wrap with a newline after the end of a sentence.
- Use the simple variant of quotes, e.g. `'` instead of `’`.
